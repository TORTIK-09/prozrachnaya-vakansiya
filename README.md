# Прозрачная вакансия

Сервис получает вакансии Калининградской области с портала «Работа в России» и формирует отчёт о том, насколько понятно описаны условия работы: пропуски, неоднозначности и противоречия с конкретной рекомендацией, что уточнить у работодателя.

Тестовое задание онлайн-отбора КАНТКОД. Проект в разработке; этот README — рабочий, итоговый текст для жюри готовит часть 5.

## С чего начать участнику команды

1. Прочитать [общий контракт](docs/spec/00-contract.md) — устройство проекта, форматы, команды, правила работы.
2. Прочитать свою спецификацию и ответить на «вопросы на старте» в общем чате.
3. Склонировать репозиторий, выполнить `uv sync` и `uv run pytest`.

| № | Область | Спецификация |
|---|---|---|
| 1 | Данные и автоматизация | [01-data.md](docs/spec/01-data.md) |
| 2 | Анализатор и модель | [02-analyzer.md](docs/spec/02-analyzer.md) |
| 3 | Качество | [03-quality.md](docs/spec/03-quality.md) |
| 4 | Свой сценарий и интерфейс | [04-extra.md](docs/spec/04-extra.md) |
| 5 | README, видео, сдача | [05-delivery.md](docs/spec/05-delivery.md) |

Требования задания списком — в [docs/task.md](docs/task.md).

## Что уже есть

- `pv/models.py` — общие типы: вакансия, замечание, проверка замечания.
- `examples/sample_vacancies.json` — учебный набор от организаторов, десять вакансий.
- `tests/test_models.py` — тесты контракта.

## Установка

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run pytest
```
