# Сценарий видео (до 3 минут)

Задание требует показать три вещи: как сервис получает данные, где применяет ИИ и какой результат выдаёт. Ниже — раскладка по времени, что на экране и что говорить.

## До записи

- Запустить панель: `uv run python -m pv web`, открыть http://127.0.0.1:8085.
- Заранее собрать отчёт «Вакансии с портала» (с моделью это долго), чтобы в кадре не ждать.
- Убедиться, что модель откалибрована: в шапке имя модели без слова «калибруется».
- Закрыть лишние вкладки, почту и мессенджеры; в кадре не должно быть ключей и личной переписки.
- Открыть второй вкладкой терминал в папке проекта.

## Раскладка

| Время | На экране | Что сказать |
|---|---|---|
| 0:00–0:15 | Первый экран панели | «Прозрачная вакансия» получает вакансии Калининградской области с портала «Работа в России» и показывает редактору, что в них описано непонятно и что уточнить у работодателя. |
| 0:15–0:45 | Терминал: `uv run python -m pv run --max 200`, строки «страница 1… страница 2…»; затем файл `.github/workflows/schedule.yml` | Данные приходят через API региона 39, постранично. Тот же процесс запускается по расписанию — вот файл расписания — и вручную одной командой. Если портал недоступен, сервис сообщает об ошибке и сохраняет последний успешный отчёт. |
| 0:45–1:25 | Панель: вакансия с противоречием (DEMO-39-004), цитаты подсвечены в тексте | Каждую вакансию проверяют двое. Системный AI — встроенный алгоритм на правилах — находит пропуски и расхождения между полями. Вот противоречие: в обязанностях «полностью дистанционно», в требованиях «ежедневно в офисе». Обе цитаты дословные и подсвечены в тексте вакансии. |
| 1:25–2:00 | Замечание с метками «Системный AI» и «ИИ»; блок «Выбор за вами»; окно «Настройки ИИ» | Языковая модель разбирает вакансию независимо. У каждого замечания видно, кто его видит. Если оба согласны — формулировку даёт ИИ. Если расходятся — редактор выбирает ответ. Цитаты модели сверяются с текстом: выдуманное отбрасывается. Модель любая — локальная через Ollama без ключа и аккаунта или облачная. |
| 2:00–2:25 | Страница «Статистика»: таблица пяти режимов | Незнакомую модель сервис сначала калибрует на размеченных вакансиях и решает, каким её замечаниям верить. Здесь измеренные показатели режимов: что находит Системный AI, что модель и что вместе. |
| 2:25–2:45 | Вкладка «Резюме под вакансию» | Дополнительный сценарий: черновик резюме под выбранную вакансию. Навыки и опыт берутся только из исходного резюме — сервис переставляет, но ничего не дописывает, — плюс вопросы работодателю по найденным замечаниям. |
| 2:45–3:00 | Терминал: `uv run python -m pv check examples/sample_vacancies.json --out reports/check.json`, затем открытый JSON отчёта | Проверочный режим — одна команда на любом JSON в формате портала, без обращения к сети. Результат — отчёт в JSON: по каждой вакансии ID, ссылка и массив замечаний. |
