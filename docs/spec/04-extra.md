# Часть 4. Свой сценарий и интерфейс

Сначала прочитайте `00-contract.md`.

## Цель

Необязательная часть задания: показать собственный сценарий на данных API региона 39 и дать отчёту вид, который удобно смотреть на видео. Базовый отчёт важнее: если времени не хватает, эта часть сокращается первой.

## Вопросы на старте — решить в первый час и написать в общий чат

**1. Какой сценарий делаем.** Варианты:

| Сценарий | Кому помогает | Что нужно |
|---|---|---|
| Черновик резюме под вакансию (пример из задания) | Соискателю | Вымышленное резюме + вакансия → переписанное резюме с акцентом на требования вакансии |
| Письмо работодателю с вопросами | Редактору вакансии | Готовый отчёт → текст письма с перечнем уточнений по одной вакансии или по всем вакансиям одного работодателя |
| Сводка по работодателям | Службе занятости | Готовый отчёт → какие организации чаще всего публикуют непонятные вакансии и что именно у них не так |

Второй и третий строятся прямо на базовом отчёте и продолжают его логику; первый — отдельная задача с отдельным запросом к модели. Выберите один.

**2. Интерфейс.** Нужна ли страница для просмотра отчёта. Предлагаю одну статичную HTML-страницу, которая читает JSON отчёта: список вакансий, замечания с подсвеченными цитатами, фильтр по теме. Без сервера и без сборки — открывается двойным щелчком и хорошо выглядит на видео.

## Что должно работать

### Сценарий
- Запускается отдельной командой, например `uv run python -m pv.extra ...`; базовый отчёт от него не зависит.
- Использует данные API региона 39 — напрямую или через готовый отчёт.
- Модель берётся через тот же клиент `pv/llm.py`, что и в анализаторе.

Если выбран черновик резюме:
- резюме только вымышленные или обезличенные — настоящих в репозитории быть не должно;
- опыт, навыки и образование берутся только из исходного резюме. Модель не имеет права добавить навык или место работы, которых там нет. Проверяйте это кодом: каждое утверждение черновика должно находиться в исходном резюме;
- результат — текст черновика и список того, что в вакансии требуется, а в резюме не найдено.

### Интерфейс
- Одна страница, читает файл отчёта, выбранный пользователем.
- Текст вакансий и замечаний вставляется как текст, а не как HTML: в вакансиях встречается разметка.
- Внешних скриптов и шрифтов нет — страница работает без сети.
