## 1. Запуск с нуля по README

Работать в новой папке, где проекта ещё не было. Выполнять только то, что написано в разделе «Быстрая проверка» README, ничего не додумывая.

| Шаг | Получилось с первого раза? | Что пошло не так |
|---|---|---|
| Репозиторий открывается в браузере без входа в аккаунт | | |
| `git clone` | | |
| `uv sync` (сколько секунд: …) | | |
| `uv run python -m pv check examples/sample_vacancies.json --out reports/check.json` | | |
| В `reports/check.json` десять вакансий | | |
| `uv run python -m pv web`, страница http://127.0.0.1:8085 открывается | | |
| `uv run pytest` — все тесты проходят (сколько: …) | | |
